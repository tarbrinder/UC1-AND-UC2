RFQ Walkthrough — one flow, intelligence at every step

Product + Qty→ GLID Pull · 7 signals→ Buyer Twin→ Intent-first (1 tap)→ Planner ≤3 Q→ Specs (auto-filled, editable)→ Deduced delivery/payment→ Enriched BL
  • Pull = PNS · CSL · WhatsApp · prev BL · prev ISQ · buyer profile → one webhook.
  • Intent-first: the WHY question comes before any spec — replaces the old “who’s buying” toggle.
  • Planner asks only the unknowns — anything the Twin already knows is skipped (and shown in “Why skipped”).
  • Specs auto-fill from a single signal (cascade), then re-rank to the buyer’s intent.
  • Last page is deduced — delivery/payment pre-filled (confirmable), not asked blank.
